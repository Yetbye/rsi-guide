## 研究进展（摘要）

提出 **无噪流匹配（Noise-Free Flow Matching）** 范式：把语义分割从像素级分类重定义为预训练潜在空间中的确定性流传输问题，实现单步推理。TriFlow 将时间域从 [0,1] 拓展到 **[-1,1]**，在同一时间轴锚定三个模态——弱光图 (t=-1)、分割掩码 (t=0)、增强图 (t=1)，用一套共享参数支持六向全连接模态转换（弱光↔分割、分割↔增强、弱光↔增强）。

已在 ring / swiss roll / two moons 三个 2D 分布上验证传输可行性；预训练 Stable Diffusion v2.1 主实验分割效果达 SOTA。
